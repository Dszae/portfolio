# Security Policy

## Supported Scope

Security reports are accepted for this repository's code and deployment-related configuration.

## Reporting a Vulnerability

If you discover a security issue, please report it privately:

- Email: **dsz.ae18@gmail.com**
- Subject: `Security report: portfolio repository`

Please include:

- Description of the issue
- Reproduction steps or proof of concept
- Impact assessment
- Suggested remediation (if available)

Do **not** open public issues for unpatched vulnerabilities.

## Disclosure

After verification and remediation, coordinated disclosure can be discussed with the maintainer.
